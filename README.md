# LAB
# Программа для вычисления параметров окружности
Данная программа написана на C++, вычисляет основные параметры окружности: длину окружности, площадь круга и площадь кругового сектора. Для вычисления необходимо ввести радиус окружности и угол сектора в градусах.
# Функциональность:
Функция `circle()` выполняет:
1. Ввод радиуса окружности
2. Ввод угла сектора
3. Вычисление:
   - Длины окружности по формуле `2 * π * r`
   - Площади круга по формуле `π * r²`
   - Площади сектора по формуле `(a/360) * π * r²`
4. Вывод результатов вычислений
# Обработка ошибок
Программа проверяет корректность ввода, то есть:
- Радиус должен быть положительным числом
- Угол сектора должен быть в диапазоне от 0 до 360 градусов

При вводе некорректных данных программа выводит сообщение об ошибке и запрашивает повторный ввод.
